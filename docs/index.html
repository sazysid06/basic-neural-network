🧠 Basic Neural Network with PyTorch

A beginner-friendly implementation of neural networks for regression

📖 Overview

This project demonstrates the fundamentals of neural networks including:

  • Network architecture (input, hidden, and output layers)
  • Forward and backward propagation
  • Activation functions (ReLU)
  • Loss functions (Mean Squared Error)
  • Optimization with Stochastic Gradient Descent (SGD)
  • Training and evaluation on real data

📊 Dataset

  • California Housing Dataset (from scikit-learn)
  • Input Features: 8 (latitude, longitude, housing median age, etc.)
  • Target: Median house value
  • Samples: 20,640 (80% training, 20% testing)

🏗️ Model Architecture

Layer Type Neurons Activation
Input Layer Dense 8 —
Hidden Layer Dense 32 ReLU
Output Layer Dense 1 Linear

⚙️ Hyperparameters

  • Learning Rate: 0.01
  • Batch Size: 64
  • Number of Epochs: 100
  • Optimizer: Stochastic Gradient Descent (SGD)
  • Loss Function: Mean Squared Error (MSE)

📈 Results

The model achieves good performance with decreasing loss over epochs:

  • Training Loss (Final): ~0.32
  • Test Loss: ~0.33

# Create virtual environment

# Install dependencies

# Run the model
